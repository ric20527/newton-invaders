# Newton Invaders - Physics Edition 🚀

Un juego educativo estilo Space Invaders desarrollado en JavaScript Vanilla para enseñar las **Leyes de Newton**.

## Características
- **Mecánica Progresiva**: 3 niveles con diferentes formas de enemigos (Cuadrados, Rombos, Triángulos).
- **Sistema de Evaluación**: Al recoger items "Newton", el juego se pausa para una pregunta técnica.
- **Power-ups**: Responder correctamente mejora el ancho del proyectil y la cadencia de fuego.
- **Registro de Estudiantes**: Al finalizar, genera un reporte descargable en JSON con el nombre, puntaje y detalle de respuestas.

## Cómo usar
1. Sube estos archivos a un repositorio de GitHub.
2. Ve a **Settings > Pages**.
3. Selecciona la rama `main` y guarda. 
4. Tu juego estará disponible en `https://tu-usuario.github.io/nombre-del-repo/`.

## Propósito Educativo
Diseñado para estudiantes de secundaria para reforzar:
1. Ley de Inercia.
2. Relación Fuerza, Masa y Aceleración.
3. Acción y Reacción.
